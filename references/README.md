# References

duplicating: frameworks, patterns, examples, and the authoring **schemas** in
[`schemas/`](schemas/) (`SKILL.template.md`, `PROMPT.template.md`,
`WORKFLOW.template.md`).

Keep durable, project-wide standards in the global files (`../DESIGN.md`,
`../AGENTS.md`) — references are for reusable knowledge and starting points, not
one-off project facts.
