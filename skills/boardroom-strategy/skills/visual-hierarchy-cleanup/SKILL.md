# Visual Hierarchy Cleanup

## When to use
Use this when a slide is technically complete but visually noisy. It establishes a clear hierarchy from title to proof to detail, removes competing elements, and enforces consistent alignment and spacing, so the board reads the point before the clutter.

## Instructions
1. Identify the one element that should be seen first and make it visually dominant.
2. Establish a clear path from action title to proof point to supporting detail.
3. Remove or demote anything that competes with the primary message.
4. Apply consistent alignment, spacing, and a restrained color and font system.
5. Squint-test the slide and confirm the takeaway is obvious within a few seconds.

## Example prompts
- "Clean up this cluttered slide so the message reads in three seconds."
- "Fix the visual hierarchy so the board's eye goes straight to the takeaway."

## Output
A list of layout and emphasis fixes, a stated hierarchy order, and consistency rules to apply deck-wide.
