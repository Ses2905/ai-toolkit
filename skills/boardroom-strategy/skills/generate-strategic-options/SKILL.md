# Generate Strategic Options

## When to use
Use this when you are about to recommend something but have not laid out the alternatives. It generates three to five real, differentiated options plus a do-nothing baseline, so the board sees a genuine choice rather than a single pre-cooked answer.

## Instructions
1. Restate the decision and the boundaries within which options must fit.
2. Generate three to five options that are genuinely distinct strategic directions, not variations of one.
3. Always include a do-nothing or status-quo baseline as a reference option.
4. Check that the options are mutually exclusive and together cover the realistic solution space.
5. Describe each option in one tight paragraph covering what it is and how it differs.

## Example prompts
- "Generate a set of distinct strategic options for entering this market, including doing nothing."
- "Give me three to five real alternatives for this decision, not variations of the same idea."

## Output
A labeled list of options, each with a one-paragraph description, plus a distinctiveness and coverage check.
