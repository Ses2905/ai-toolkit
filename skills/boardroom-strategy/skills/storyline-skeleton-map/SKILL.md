# Storyline Skeleton Map

## When to use
Use this to design the deck on one page before producing slides. It sequences every slide's core message so that, read top to bottom, the titles alone form a persuasive argument from question to recommendation, exposing gaps and detours early.

## Instructions
1. List the intended slide messages in order, each as a single declarative sentence.
2. Check that the sequence flows as either a grouping or an argument chain with no logical leaps.
3. Read only the messages end to end and confirm they tell the complete story without the slides.
4. Cut, merge, or reorder any message that is a detour from the governing question.
5. Mark where evidence will be needed and where the recommendation and ask will land.

## Example prompts
- "Lay out the narrative spine for my strategy deck as an ordered list of slide messages."
- "Build a storyline skeleton so my slide titles alone tell the whole argument."

## Output
A numbered outline of one-line slide messages with a spine-read check and flagged evidence points.
