# Quantify The Gap

## When to use
Use this when a claim needs a number behind it. It establishes a baseline, defines the target, computes the gap, and translates it into value at stake with assumptions exposed, so the magnitude is credible and the math survives CFO scrutiny.

## Instructions
1. Establish the current baseline with its source and time frame.
2. Define the target or benchmark and where it comes from.
3. Calculate the gap and convert it into value at stake (revenue, cost, or margin).
4. List every assumption and driver feeding the calculation in plain view.
5. Provide a conservative and an aggressive bound so the number reads as a defensible range.

## Example prompts
- "Size the revenue gap between where we are and the target, and show the value at stake."
- "Quantify this opportunity with transparent assumptions and a low-high range."

## Output
A baseline-to-target calculation with the sized gap, value at stake, a low-high range, and an assumptions list.
