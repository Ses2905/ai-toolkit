# Synthesize So Whats

## When to use
Reach for this when you have lots of data but no message. It groups raw findings, extracts the "so what" from each, rolls them up into one governing insight, and links each insight to the evidence that backs it, ready to feed the storyline.

## Instructions
1. Gather all findings and group them by theme or by the branch of the issue tree they answer.
2. For each finding, force a "so what" that states why a decision-maker should care.
3. Discard observations that have no decision-relevant so-what.
4. Roll the surviving so-whats up into one governing insight that points to the recommendation.
5. Tie each insight back to its supporting evidence so every claim is traceable.

## Example prompts
- "Turn these analysis findings into a few sharp so-whats and one governing insight."
- "Synthesize my diagnostics into decision-relevant insights linked to the evidence."

## Output
Grouped findings with a so-what each, a single governing insight, and an evidence map.
