# Tradeoff Analysis

## When to use
Use this when no option is best on everything. It defines and weights the criteria that matter, scores each option, and names the specific trade-off each choice forces, so the board decides with eyes open rather than being sold a free lunch.

## Instructions
1. List the decision criteria that matter and assign each a transparent weight.
2. Score each shortlisted option against every criterion.
3. Compute a weighted view while showing the raw scores behind it.
4. State explicitly what each option sacrifices to win where it wins.
5. Recommend the balance of criteria the decision should optimize for and why.

## Example prompts
- "Score these options against weighted criteria and make the trade-offs explicit."
- "Help me show what we give up with each option so the board chooses with eyes open."

## Output
A weighted scorecard with per-criterion scores, an explicit trade-off statement per option, and a recommended weighting.
