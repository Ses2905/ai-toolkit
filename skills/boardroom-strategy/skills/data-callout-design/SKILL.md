# Data Callout Design

## When to use
Use this when a chart shows everything and emphasizes nothing. It picks the single data point that proves the slide's title, applies an accent highlight, and writes a short directional callout, so the eye lands on the message in under three seconds.

## Instructions
1. Identify the one number or trend on the chart that proves the action title.
2. Strip clutter and gridlines that compete with that point.
3. Apply a single accent color or marker to the proof point and mute everything else.
4. Write a short, directional callout in plain language next to it.
5. Confirm the chart, callout, and action title all say the same one thing.

## Example prompts
- "Design the callouts on this chart so the board instantly sees the number that matters."
- "Highlight and annotate this data slide so it proves my action title at a glance."

## Output
A callout plan listing the highlighted point, accent treatment, annotation text, and a chart-to-title alignment check.
