# Metrics And Milestones

## When to use
Use this to close the loop on accountability. It selects the few metrics that prove success, sets targets against baselines, adds leading indicators that signal trouble early, and ties them to review checkpoints, so the board can track whether the bet is paying off.

## Instructions
1. Choose the few outcome metrics that genuinely prove the strategy worked.
2. Set a target and a baseline for each so progress is measurable.
3. Add leading indicators that move before the outcome metrics do.
4. Tie each metric to a review checkpoint and an owner.
5. Define what a red, amber, or green reading means so reviews are objective.

## Example prompts
- "Define the success metrics, targets, and leading indicators for this strategy."
- "How will we measure and track whether this plan is working, with checkpoints?"

## Output
A metrics table with targets, baselines, leading indicators, checkpoints, and red-amber-green thresholds.
