# 25 Claude Skills to Build Boardroom Strategy Decks

A focused, install-on-demand skill set for taking a strategy question all the way to a
board-ready presentation deck. The 25 skills run across five stages: framing the mandate,
diagnostics and evidence, strategic choices, execution planning, and narrative and
communication (including slide action titles and data callouts). Each skill names the
generic technique it uses, the steps it follows, and the deliverable it produces.

## What's inside

1. **Define Governing Question** - Converts a broad executive request into one specific, decision-forcing governing question that the entire deck must answer, used at the very start of any strategy engagement.
2. **Audience Stakeholder Map** - Profiles the board and executive audience so the deck speaks to their priorities, sophistication, and biases, used after the question is set but before drafting the storyline.
3. **SCQA Situation Frame** - Builds the opening context using a situation-complication-question structure so the audience arrives at the governing question feeling it is inevitable, used when crafting the deck's first movement.
4. **Working Hypothesis Answer** - States an explicit answer-first hypothesis and the few things that must be true for it to hold, used right after framing to give the analysis a target to confirm or kill.
5. **Storyline Skeleton Map** - Lays out the full deck as an ordered sequence of one-line slide messages that read as a self-contained argument, used to design the narrative spine before content is built.
6. **Issue Tree Decomposition** - Breaks the governing question into a mutually exclusive, collectively exhaustive tree of sub-questions so analysis is complete without overlap, used to scope what to investigate.
7. **Root Cause Driver Tree** - Maps a headline metric down through its mathematical and causal drivers to isolate root causes and size each one's contribution, used to explain why a number is moving.
8. **Quantify The Gap** - Sizes the gap between current and target performance and the value at stake using transparent assumptions, used to turn a qualitative problem into a defensible number.
9. **Benchmark And Compare** - Positions performance against relevant peers, history, or external standards to reveal where the organization leads or lags, used to give a metric context.
10. **Synthesize So Whats** - Distills a pile of analytical findings into a small set of decision-relevant insights and the single governing so-what, used to bridge from evidence to recommendation.
11. **Generate Strategic Options** - Produces a small set of genuinely distinct, mutually exclusive strategic options including the status-quo baseline, used to give the decision real alternatives to weigh.
12. **Prioritization Matrix** - Scores and plots options on a two-by-two of the two most decision-relevant dimensions to produce a defensible priority order, used to narrow a long list to a focused few.
13. **Scenario Stress Test** - Tests how each option performs across a small set of high-impact, high-uncertainty future scenarios to find the most robust choice, used when uncertainty could break a single-point plan.
14. **Tradeoff Analysis** - Evaluates options against weighted decision criteria and makes the sacrifices explicit so the choice is honest about what is being given up, used to resolve close calls.
15. **Recommendation Statement** - Crafts a single committed recommendation with its rationale, the specific ask, and the conditions under which it holds, used to convert analysis into a decision the board can approve.
16. **Implementation Roadmap** - Sequences the recommendation into phased workstreams with milestones, dependencies, and owners on a timeline, used to show the path from decision to delivered value.
17. **Resource And Investment Plan** - Builds the cost, investment, and expected-return picture for the recommendation including phasing and payback, used to define exactly what the board is being asked to fund.
18. **Risk And Mitigation Register** - Identifies the key risks to the recommendation, rates their likelihood and impact, and pairs each with a mitigation and owner, used to demonstrate the downside is controlled.
19. **Operating Model And Owners** - Defines who owns delivery, how decisions get made, and the governance cadence that keeps the plan on track, used to make accountability unambiguous.
20. **Metrics And Milestones** - Defines the success metrics, targets, leading indicators, and checkpoints that will prove the strategy is working, used to make the plan measurable and accountable.
21. **Action Title Writing** - Writes assertive, insight-bearing action titles that state each slide's takeaway so the titles alone tell the story, used to make the deck skimmable and argument-driven.
22. **Data Callout Design** - Designs the callouts, highlights, and annotations on a data slide so the audience instantly sees the one figure that supports the action title, used to make charts argue rather than just display.
23. **Executive Summary Slide** - Builds the one-page executive summary that leads with the recommendation and compresses context, rationale, and the ask so a decision can be made from this slide alone, used as the deck's opener or leave-behind.
24. **Visual Hierarchy Cleanup** - Restructures a slide's layout, emphasis, and white space so the eye follows the intended message path and nothing competes with the takeaway, used to make slides read in seconds.
25. **Objection And QA Prep** - Anticipates the toughest board questions and objections and prepares crisp answers, deciding which to pre-empt in the deck and which to hold for live Q&A, used to make the presenter unshakeable.

## How to install

You need a Claude subscription (claude.ai) or Claude Code.

- **Claude.ai Project:** create a Project, open its knowledge / files panel, and upload the
  `SKILL.md` files for the skills you want (one folder each under `skills/`). Claude will
  use them on demand when your prompt matches.
- **Claude Code:** drop the skill folders from `skills/` into `~/.claude/skills/` so they
  are available to every session.

Then just ask in plain language, e.g. "Use the storyline-skeleton-map skill to outline a
board deck on entering a new segment," or "Apply action-title-writing to sharpen these
slide headers." Install one skill, a stage, or the whole set.
