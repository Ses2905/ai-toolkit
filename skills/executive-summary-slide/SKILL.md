# Executive Summary Slide

## When to use
Reach for this to build the slide that decides approval. It puts the recommendation sentence first and largest, follows with the three supporting pillars and the specific ask, so a busy executive who reads only this page still gets the full decision.

## Instructions
1. Lead with the recommendation as the first and most prominent text element.
2. Add a one-line situation-and-complication frame so the recommendation has context.
3. Summarize the two or three pillars that support the recommendation.
4. State the explicit ask and what approval unlocks.
5. Trim until a reader could approve from this slide alone, then check it stands without the rest of the deck.

## Example prompts
- "Build the executive summary slide that leads with the recommendation and the ask."
- "Compress my whole deck into one decision-ready summary slide."

## Output
A one-slide layout with a lead recommendation line, brief context, supporting pillars, and the ask.
