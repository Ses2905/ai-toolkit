# Implementation Roadmap

## When to use
Use this once a direction is chosen and the question becomes "how and when." It breaks delivery into phases with concrete milestones, surfaces dependencies and critical path, and assigns owners, so the board sees a credible, time-bound route to value.

## Instructions
1. Break the recommendation into a few logical phases or workstreams.
2. Define the concrete milestone and deliverable that ends each phase.
3. Map dependencies and the critical path between milestones.
4. Assign a single accountable owner to each workstream.
5. Place everything on a timeline with realistic durations and early quick wins called out.

## Example prompts
- "Build a phased implementation roadmap with milestones and owners for this strategy."
- "Lay out the timeline, dependencies, and quick wins to deliver this recommendation."

## Output
A phased timeline with milestones, dependencies, owners, and flagged quick wins.
