# SCQA Situation Frame

## When to use
Use this to write the setup that earns attention in the first ninety seconds. It states the stable situation everyone agrees on, the complication that breaks it, and the question that complication forces, so the audience is already nodding when you reach your recommendation.

## Instructions
1. Write the Situation as a non-controversial fact base the audience already accepts.
2. Write the Complication as the change, threat, or tension that disrupts that situation.
3. Derive the Question that the complication naturally raises and align it to the governing question.
4. Pressure-test that the question feels inevitable given the situation and complication, with no logical gap.
5. Draft a tight three-to-five-sentence opening frame ready to become the first slide or two.

## Example prompts
- "Use a situation-complication-question structure to open my market-entry deck."
- "Draft an SCQA frame that makes the board feel my strategy question is unavoidable."

## Output
Four labeled blocks (Situation, Complication, Question) plus a ready-to-use opening paragraph.
