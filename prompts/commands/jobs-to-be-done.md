# Jobs to be done

## Use For
Mapping a segment or product's customer jobs, pains, and gains.

## Prompt
Treat any text after the slash command as the input; if none was given, ask for it once.

Use the **jobs-to-be-done** skill (`skills/jobs-to-be-done/SKILL.md`) to produce this. Follow its process, decision rules, and definition of done — the skill is the single source of truth for the method, so it is not restated here.

## Expected Output
A structured JTBD breakdown: functional / social / emotional jobs, pains, and gains, with unmet-need signals.
