# Proto persona

## Use For
Creating a working, assumption-based persona for a target user or segment.

## Prompt
Treat any text after the slash command as the input; if none was given, ask for it once.

Use the **proto-persona** skill (`skills/proto-persona/SKILL.md`) to produce this. Follow its process, decision rules, and definition of done — the skill is the single source of truth for the method, so it is not restated here.

## Expected Output
A proto-persona: goals, behaviors, context, pains/gains, and the assumptions that still need validation.
