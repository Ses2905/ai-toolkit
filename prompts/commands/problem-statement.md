# Problem statement

## Use For
Writing a user-centered problem statement for a specific user and their struggle.

## Prompt
Treat any text after the slash command as the input; if none was given, ask for it once.

Use the **problem-statement** skill (`skills/problem-statement/SKILL.md`) to produce this. Follow its process, decision rules, and definition of done — the skill is the single source of truth for the method, so it is not restated here.
