# Epic hypothesis

## Use For
Framing one initiative/epic as a testable hypothesis before roadmap or delivery.

## Prompt
Treat any text after the slash command as the input; if none was given, ask for it once.

Use the **epic-hypothesis** skill (`skills/epic-hypothesis/SKILL.md`) to produce this. Follow its process, decision rules, and definition of done — the skill is the single source of truth for the method, so it is not restated here.

## Expected Output
An if/then hypothesis with the target user, expected outcome, validation method, and a lightweight experiment.
